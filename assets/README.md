# Assets

Models and environment maps the game loads at start-up. **These files are not in the repository** (they are ignored
by git). Copy them here yourself.

| File | What it is | Licence |
| --- | --- | --- |
| `car/porsche-992-gt3rs-2023.sog` | Splat model of a 2023 Porsche 911 GT3 RS (SOG v2). | CC BY 4.0, creator b2mbiczek. A real car model: review before any public release. |
| `hdri/studio_sun.hdr` | Environment map (equirectangular, 2:1). | Not recorded in this repository. Leave the setting empty to use the built-in sky instead. |

`car/ATTRIBUTION.md` and `car/porsche-992-gt3rs-2023.source.json` (where the model came from, and its checksums) are
kept in the repository even though the model is not.
